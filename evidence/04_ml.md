## Notes & decisions

- **Serving fallback**: real-time Model Serving requires a *registered* model, but this metastore
  is at its UC registered-model quota (5000) and the legacy workspace registry is disabled. So the
  app/agent consume the model two ways that need no endpoint: (1) precomputed batch predictions in
  UC tables `policylens_ml.financial_impact_predictions` / `policy_cpt_predicted_annual`, and
  (2) ad-hoc what-if by loading the logged model via `mlflow.pyfunc.load_model("runs:/<id>/model")`.
  If UC model quota is freed, the same model can be registered and served with no code changes.
- **Gap classifier scope**: trained on 72 EBCBS×competitor comparisons with rule-derived labels —
  a compact demonstrator of the MLflow multiclass workflow. The **authoritative** gap detection is
  the Step-3 gold `policy_gap_alerts` (rule-based), which correctly flags all three seeded gap types
  including spine as `more_restrictive`.
- **Financial model R²**: high (0.998 on log target) because monthly allowed $ is strongly driven by
  procedure cost/category with stable per-CPT volume; SHAP confirms cost/category dominate.
